# ① 起動のしくみ

電源を入れてから自分のプログラムが動くまでの流れ。

## 全体の流れ

```
① 電源ON
   │  CPUがリセットされ、決まった番地から実行を始める
   ▼
② BIOS(マザーボードに最初から入っているプログラム)
   │  ハードウェアの点検と初期化(POST)
   │  起動できるディスクを順番に探す
   ▼
③ ディスクの先頭512バイト(ブートセクタ)をメモリの 0x7C00 番地に読み込む
   │  最後の2バイトが 55 AA なら「起動できる」と判断する
   ▼
④ 0x7C00 番地にジャンプする
   ▼
⑤ ここからが自分のプログラム(boot.asm)
```

QEMU の画面との対応:

```
SeaBIOS (version 1.17.0 ...)      ← BIOSが起動した(SeaBIOS は QEMU の BIOS)
iPXE (https://ipxe.org) ...       ← ネットワーク起動機能の案内(使わない)
Booting from Hard Disk...         ← ハードディスク(build/os.img)から起動する
Stage 1: ...                      ← ここから自分のプログラムの出力
```

## ポイント

### 起動直後のCPUは16ビットのリアルモード

1978年の 8086 との互換性のため、今の64ビットCPUでも起動直後は16ビットで動く。`[bits 16]` はそのため。使えるメモリは先頭の1MBだけ。

### BIOS は最初の案内役

- ハードウェアの点検と初期化
- 起動ディスクを決められた順番で探す
- 便利な機能を提供する: 文字表示(`int 0x10`)、ディスク読み込み(`int 0x13`)、キー入力(`int 0x16`)など

BIOS の機能はリアルモードでしか使えない。32ビットモードに切り替える前に、BIOS に頼む用事を済ませておく必要がある。

### ブートセクタは512バイト、最後に `55 AA`

```nasm
times 510 - ($ - $$) db 0   ; 510バイト目まで0で埋める
dw 0xaa55                   ; 最後の2バイトに 55 AA を置く
```

`dw 0xaa55` を消すと、BIOS は「起動できない」と判断して止まる。

### なぜ 0x7C00 番地?

1981年の初代 IBM PC が決めた番地で、それ以来変わっていない。当時の最小構成のメモリ(32KB)の終わりから1KB手前で、BIOS の領域とぶつからない場所。

`[org 0x7c00]` は「自分は 0x7C00 に置かれる」と nasm に教えるもの。これがないとラベル(文字列など)の番地の計算がずれる。

### 最初にやること: 状態の初期化

BIOS から渡された直後のレジスタの値はまちまちなので、セグメントレジスタを0にし、スタック(`sp`)の位置を決める。スタックは 0x7C00 から小さい番地に向かって伸びるので、プログラム本体とはぶつからない。

### 最後は `hlt` で止める

やることがなくなったら `hlt` で CPU を止める。これがないと、CPU は文字列などのデータを命令だと思って実行し、暴走する。

## リアルモードのメモリの地図

```
0x00000 ┌──────────────────────┐
        │ BIOSが使う領域        │  割り込みの一覧など(触らない)
0x00500 ├──────────────────────┤
        │ 自由に使える          │  ← スタックはここを下に伸びる
0x07C00 ├──────────────────────┤
        │ ブートセクタ(512B)   │  ← boot.asm
0x07E00 ├──────────────────────┤
        │ 自由に使える(約480KB)│  ← stage2.asm を読み込む
0x9FC00 ├──────────────────────┤
        │ BIOSの拡張データ      │
0xA0000 ├──────────────────────┤
        │ 画面のメモリ(VRAM)   │  ← ④のグラフィックで使う
0xC0000 ├──────────────────────┤
        │ BIOS本体など          │
0xFFFFF └──────────────────────┘
```

## 補足: UEFI

最近の PC は BIOS の後継の UEFI で起動する(最初から64ビット、512バイト制限なし)。このリポジトリでは、しくみが単純で CPU の動きを一番下から理解できる BIOS 方式(QEMU の SeaBIOS)を使う。
